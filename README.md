# Fittology — сайт фитнес-клуба с аутентификацией

## Структура проекта
```
server.js              — точка входа, настройка сессий, статика, защищённый роут
routes/auth.js         — register / login / logout / session (API)
middleware/requireAuth.js — проверка входа для защищённых страниц
utils/validators.js    — валидация логина/пароля (вынесена отдельно ради unit-тестов)
tests/                 — unit-тесты (node --test)
db/database.js         — подключение к SQLite и создание таблицы users
data/fitness.db         — сама база (появится после первого запуска)
public/                — весь исходный сайт (HTML/CSS/JS/картинки) + login.html, register.html
THREATS.md             — описание угроз и защиты от них
```

## Как запустить
Понадобится установленный Node.js 

```bash
npm install
npm start
```

Сайт будет доступен на **http://localhost:3000** (обычный HTTP — как и был).

Дополнительно сервер сразу поднимает и HTTPS-версию на **https://localhost:3443** —
с самоподписанным сертификатом из папки `certs/` (создан только для демонстрации, не для
реального использования). При открытии `https://localhost:3443` 

Первый запуск сам создаст пустую базу данных `data/fitness.db` — регистрируйте пользователя
через `/register.html` и дальше пробуйте вход/выход и доступ к «Клубным картам».

## Unit-тесты
```bash
npm test
```
Проверяют изолированно (без сервера и без БД): валидацию логина/пароля, детектор клавиатурных
паттернов, обёртку над списком частых паролей и корректность хэширования/проверки Argon2
(round-trip: хэшируем — проверяем тем же паролем — должно быть true; другим — false). 30 тестов,
запускаются встроенным в Node.js тест-раннером (`node --test`), дополнительных зависимостей не
требует.

## Важно
Сейчас `SESSION_SECRET` генерируется случайно при каждом запуске (что обнуляет все активные
сессии при перезапуске сервера) и `secure`-cookie отключена, чтобы всё работало на `http://localhost`
без сертификата. Для реального продакшена: задать `SESSION_SECRET` через переменную окружения,
запустить с `NODE_ENV=production` и поставить сайт за HTTPS.
